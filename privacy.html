1. 이 앱은 무엇인가요

교사가 수행평가 답안을 채점하고 세특 초안을 쓰도록 돕는 웹앱입니다. 운영자가 따로 두는 서버가 없고, 모든 처리는 교사의 브라우저에서 이루어집니다.

2. 어디에 저장되나요

  • 이 브라우저: 평가계획, 답안 그림, 채점 결과, 세특, 설정(Gemini API 키 포함)은 그 브라우저의 저장소(IndexedDB·localStorage)에 저장됩니다.
  • 교사 본인의 구글 드라이브(구글 로그인을 한 경우만): 위 자료가 로그인한 교사 본인 드라이브의 'AI 서논술형 채점' 폴더에 저장됩니다. 다른 컴퓨터에서 같은 계정으로 로그인해 이어서 쓰기 위한 것입니다.

앱 운영자는 어느 쪽 자료에도 접근할 수 없습니다.

3. 구글 계정 권한

구글 로그인 시 drive.file 권한만 요청합니다. 이 권한으로는 이 앱이 만든 파일만 보고 고칠 수 있으며, 드라이브의 다른 파일은 볼 수 없습니다. 로그인한 계정의 이메일 주소는 화면에 표시하는 용도로만 그 브라우저에 저장합니다. 구글 사용자 데이터는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라 이 기능을 제공하는 데만 쓰며, 다른 사람에게 넘기거나 광고에 쓰지 않습니다.

권한은 언제든 앱의 설정 → 로그아웃, 또는 구글 계정 → 서드 파티 연결에서 해제할 수 있습니다. 드라이브의 'AI 서논술형 채점' 폴더를 지우면 저장된 자료도 지워집니다.

4. AI 로 보내는 내용

AI 채점·세특 작성을 누를 때만, 교사가 입력한 Gemini API 키로 Google Gemini 에 채점 기준과 답안 그림을 보냅니다. 답안 그림의 이름·학번 칸은 교사가 지정한 대로 가린 뒤 보냅니다. 결제를 등록하지 않은 무료 키는 Google 이 보낸 내용을 서비스 개선에 쓸 수 있습니다.

5. 시작 화면 잠금과 방문 수

앱을 열 때 공유받은 비밀번호를 묻습니다. 비밀번호는 기기 안에서만 확인하며 어디로도 보내지 않습니다.
