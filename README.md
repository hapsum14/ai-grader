# AI 서논술형 채점

평가계획서를 올리면 수행평가 채점 기준을 뽑아 채점 계획을 세우고, 학생 답안 스캔(PDF)을 번호별로 나눠
수동 채점 · AI 루브릭 채점 · 세특 초안(수행평가 한 개당 약 250~300바이트)까지 한 화면에서 하는 웹앱입니다.
서버 없이 브라우저에서만 돌아갑니다(GitHub Pages).

## 쓰는 순서

1. **설정** — [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료로 만든 Gemini API 키를 넣습니다(이 브라우저에만 저장). "키 확인·최신 목록"을 누르면 쓸 수 있는 모델을 새 버전부터 보여 주고, 기본은 새 모델이 나오면 저절로 바뀌는 "항상 최신 Flash"입니다. 화면 위 **? 도움말**(또는 `?` 키)에 단계별 안내가 있습니다. `mock` 을 넣으면 AI 없이 화면만 시험합니다.
2. **평가계획서 올리기** — hwp · hwpx · pdf · txt. AI 가 수행평가 영역마다 채점 기준 항목, 점수 환산표(충족 항목 수 → 점수),
   특수 상황 점수(백지·결석), 성취기준·성취수준을 정리합니다. "채점 기준 보기·고치기"에서 확인하고 고칩니다.
3. **반 추가** — 반 이름, 학생 수, 학생당 쪽 수, 답안 스캔 PDF. 쪽을 나눠 번호를 붙입니다.
   - 미응시 번호를 누르면 그 번호를 건너뛰고 다시 번호를 붙입니다.
   - 나뉜 자리가 틀리면 쪽마다 "새 학생 / 이어붙이기", 표지·빈 쪽은 "빼기", 번호 칸에서 번호를 직접 고칩니다.
   - **이름 칸 가리기**: 첫 쪽의 학번·이름 칸을 넉넉하게 상자로 그리면, AI 로 보낼 때만 검게 칠합니다.
4. **채점** — 왼쪽 원본, 오른쪽 채점 기준 체크 · 점수 · 미제출/미응시 · AI 채점 근거와 피드백 · 선생님 피드백 · 세특 초안.
   - 단축키: ← → 학생 이동, 1~9 기준 체크, Ctrl+Enter 채점 완료 후 다음 학생.
   - "AI 채점 한꺼번에", "세특 한꺼번에 만들기"는 반 화면에 있습니다.
   - **채점 엄격도**(관대하게 · 보통 · 엄격하게): 답이 기준에 어느 정도 들어오면 충족으로 볼지 정합니다. 반 화면과 채점 기준 화면에서 고르고, 다음 AI 채점부터 적용됩니다. 과학적으로 틀린 답은 어느 쪽이든 미충족입니다.
   - 한꺼번에 하는 일은 화면 오른쪽 아래 작은 판에서 뒤로 돌아갑니다. 그동안 다른 반·학생을 보고 채점해도 됩니다(창을 닫거나 새로 고치면 멈춤).
5. **내보내기** — 반별 채점 결과 엑셀, 과목 화면의 "반별 세특 모아보기"(수행평가별 세특을 이어 붙인 길이와 함께) 엑셀.

## 세특 규칙

`reference/생기부_작성머신` 규칙에서 수행평가 한 개 몫에 필요한 것만 옮겼습니다.
교사 관찰 시점(~함/~임/~보임), 학생 내면 종결어 금지, 근거에 맞는 서술어 수준, 금지어(나의·내가·대회),
마침표·쉼표·하이픈 외 특수문자 금지, 상호명 → 일반 명사, 숫자는 아라비아 숫자·단위는 한글.
문장 구조는 실제 교과세특 212건의 활동 부분을 분석해 정했습니다: '○○ 수행평가에서는'으로 시작하는 두 문장(약 300바이트), 둘째 문장은 '특히/또한'·'~의 관점에서'·'~과 연계해'로 핵심 원리를 더 구체적으로,
성취 수준(충족한 기준 비율 상 80% 이상·중 50% 이상·하)에 맞는 서술어. 총평·정리 문장은 넣지 않습니다(과목 세특의 가운데 활동 부분이므로).
설정의 **세특 문체 본보기**에 예전에 쓴 세특 엑셀을 넣으면, 활동 부분 문장만 뽑아 이 브라우저에 두고 세특을 쓸 때 가까운 4개를 본보기로 함께 보냅니다(내용은 가져오지 않음).
바이트는 나이스 기준(한글 등 3바이트, 영문·숫자·공백·기호 1바이트)으로 앱이 직접 세고, 범위를 벗어나면 AI 에게 최대 3번 다시 쓰게 합니다.
남은 위반은 세특 칸 아래 빨간 글씨로 알려 줍니다.

## 화면

'생물 임용 기출 찾아보기'와 같은 구성입니다. 왼쪽 메뉴(로고 → 찾기 → 과목·반 / 채점 현황 / 도구 묶음), 위쪽 띠(지금 위치 · 도움말 · 어둡게 · 설정),
첫 화면 요약 카드(처리한 학생 · 확인할 답안 · 이어 하기)와 표 모양 목록. 색은 밝은 화면 보라, 어두운 화면 자두색(`app.css` 맨 위 토큰).
휴대폰에서는 왼쪽 메뉴가 아래 탭(과목·반 · 현황 · 도구 · 찾기)이 됩니다. 채점 화면은 넓게 쓰려고 PC 에서도 왼쪽 메뉴를 숨기고, ☰ 로 엽니다.

- 채점 현황에서 상태(채점 전 · AI 채점 · 채점 완료 · 미제출 · 미응시)를 고르면 반 목록과 채점 화면의 ← → 가 그 학생들만 오갑니다.
- 반 화면의 세특 복사(학생마다) · 세특 모두 복사(번호[탭]세특, 엑셀에 바로 붙여 넣기).
- 스캔 PDF 는 쪽마다 든 JPEG 를 그대로 꺼내 브라우저가 풀어서, 50쪽이 약 25초에 그림으로 바뀝니다(전에는 2분). 다른 모양의 PDF 는 pdf.js 로 그립니다.

## 저장과 개인정보

- 컴퓨터(브라우저)마다 따로입니다. API 키는 그 브라우저의 localStorage, 평가계획·답안 그림·채점 결과·세특은 그 브라우저의 IndexedDB 에만 저장되고 서버로 가지 않습니다. 다른 선생님은 다른 컴퓨터에서 자기 키로 따로 씁니다.
- 앱을 껐다 다시 열면 마지막으로 보던 화면에서 시작합니다. 창을 닫거나 다른 창으로 넘어갈 때 고치던 칸까지 곧바로 저장합니다.
- 한꺼번에 채점·세특 도중 창을 닫았으면 다시 열 때 오른쪽 아래에 '이어서 하기'가 나오고, 남은 학생만 이어서 합니다.
- 같은 컴퓨터라도 다른 브라우저(크롬·엣지)나 시크릿 창에서는 기록이 보이지 않습니다. 브라우저의 '인터넷 사용 기록 삭제'에서 쿠키·사이트 데이터를 지우면 기록도 지워지니, 가끔 백업 저장을 해 두세요.

- 채점 기록과 답안 그림은 이 브라우저(IndexedDB)에만 저장됩니다. 다른 컴퓨터로 옮길 때는 처음 화면의 "백업 저장/불러오기"
  (답안 그림은 빠지므로 반 화면에서 같은 PDF 를 다시 연결).
- AI 를 쓸 때만 가림 처리한 답안 그림과 채점 기준이 Google Gemini 로 전송됩니다. 결제를 등록하지 않은 무료 키는
  Google 이 보낸 내용을 서비스 개선에 쓸 수 있으니 이름 칸 가리기를 꼭 해 두세요.
- 이 저장소에는 앱 코드만 있고 학생 자료는 없습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀, 외부 도구(pdf.js, JSZip, pako, SheetJS) |
| `app.js` | 화면·데이터·채점·내보내기 |
| `ai.js` | Gemini 호출, 계획서 분석·채점·세특 지시문, `mock` 응답 |
| `parse.js` | hwp/hwpx/pdf 글 읽기, PDF → 쪽 그림, 가림 처리 |
| `app.css` | 화면 꾸밈(밝은/어두운 화면) |

## 새 판 올리기

코드를 고친 뒤 `version.json` 의 `v` 를 새 값(예: 날짜-시각)으로 바꿔 함께 올립니다. 그래야 선생님 브라우저가 예전 파일을 캐시에서 쓰지 않고 바로 새 판을 받습니다.
